# Definition
**Corrosion** is the destruction of materials by chemical reactions with the environment.

---
# Prevention
We can stop corrosion by using a barrier between the material and environment. This can be done with:
1. Grease
2. Paint
3. Electroplating 1. Coating the material with a metal.
4. Galvanising 1. Covering iron/steel with zinc as zinc is more reactive so it corrodes (sacrificial protection).
