#Chemistry/Chemical-Analysis
# Carbonate Ions
- Add dilute acid to sample.
- Acid reacts to make gas. 
- Bubble the gas through limewater.
- If $CO_2$ is present there is a carbonate ion.
# Halide Ions
- Add dilute $HNO_3$ *(nitric acid)* to sample.
- Add dilute silver nitrate solution.
- Halide ions will produce a precipitate.
	- Chloride $\rightarrow$ white
	- Bromide $\rightarrow$ cream
	- Iodide $\rightarrow$ yellow
# Sulfate Ions
- Add dilute $HCl$ to sample.
- Add Barium Chloride solution.
- If sulfate is present we will see a white precipitate.
