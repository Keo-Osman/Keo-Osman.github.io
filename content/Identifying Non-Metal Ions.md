# Carbonate Ions
1. Add dilute acid to sample.
2. Acid reacts to make gas. 
3. Bubble the gas through limewater.
4. If $CO_2$ is present there is a carbonate ion.
# Halide Ions
1. Add dilute $HNO_3$ *(nitric acid)* to sample.
2. Add dilute silver nitrate solution.
3. Halide ions will produce a precipitate.
	1. Chloride $\rightarrow$ white
	2. Bromide $\rightarrow$ cream
	3. Iodide $\rightarrow$ yellow
# Sulfate Ions
1. Add dilute $HCl$ to sample.
2. Add Barium Chloride solution.
3. If sulfate is present we will see a white precipitate.
